# reporter-skill
automatic reporter-demo
一、将系统物料中台周报Excel 拖进 AI 对话就能自动输出 PNG*4
周报：png--﹣周报可视化图（带条件格式高亮）
动画png -… 动画 TOP&BOTTOM case 列表图
影剧综 png -﹣影剧除 TOP&BOTTOM case 列表图
纪录片．png-﹣纪录片 TOP&BOTTOM case 列表图

二、我搭建skill的数据透视条件是：
1.1、数值类型数据：使用色条，数值越大，色条越长；
1.2、变化类数据：正的为绿色，负的为红色，绝对值越大，颜色越深；
1.3、百分比类型：越高的接近正红色，越接近0％用正蓝色
